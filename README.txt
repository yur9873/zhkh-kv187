ЖКХ кв-187 — Android-приложение (проект для Android Studio)

Это оболочка вокруг калькулятора: вся страница лежит внутри приложения (app/src/main/assets/index.html), работает без интернета.

КАК ПОЛУЧИТЬ APK (около 10 минут)
1. Установите Android Studio: https://developer.android.com/studio (бесплатно, Windows/Mac/Linux).
2. Распакуйте этот архив. В Android Studio: File → Open → выберите папку zhkh-android.
3. Дождитесь, пока внизу закончится «Gradle sync» (нужен интернет, студия сама докачает Android SDK 34 и всё нужное). Если студия предложит обновить плагин или скачать SDK — соглашайтесь.
4. Меню Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Справа внизу появится «APK(s) generated» → Locate. Файл: app/build/outputs/apk/debug/app-debug.apk
   (то же из терминала: ./gradlew assembleDebug, в Windows gradlew.bat assembleDebug)
6. Перенесите app-debug.apk на телефон (кабель, Telegram себе, почта, облако) и откройте его.
   Android попросит разрешить установку из этого источника — разрешите. Предупреждение Play Protect о неизвестном разработчике нормально: приложение собрано вами.

ЧТО ВАЖНО ЗНАТЬ
• Данные хранятся внутри приложения на телефоне. Если удалить приложение, данные пропадут. Нажимайте «Сохранить»: копия попадёт в папку «Загрузки».
• Кнопка «СНИМАЮ» открывает камеру телефона. Автоматическое распознавание цифр по фото работает только в версии внутри Claude. В приложении после снимка выберите счётчик и впишите показание, калькулятор проверит его по прошлому периоду и среднему расходу.
• Интернет приложению не нужен и не запрашивается. Ссылки на сайты с тарифами открываются в браузере телефона.
• Чтобы обновить калькулятор, замените файл app/src/main/assets/index.html на новую версию и соберите APK заново.

ВАРИАНТ Б: БЕЗ УСТАНОВКИ ANDROID STUDIO (APK соберёт бесплатный сервис GitHub)
1. Зарегистрируйтесь на github.com (бесплатно) и создайте новый репозиторий (можно Private).
2. На странице репозитория: Add file → Upload files. Перетащите ВСЁ содержимое папки zhkh-android,
   включая папку .github (в ней лежит сценарий сборки). Нажмите Commit changes.
3. Откройте вкладку Actions → «Build APK» → Run workflow. Сборка идёт 3–6 минут.
4. Откройте завершённый запуск, внизу в разделе Artifacts скачайте zhkh-kv187-apk (это zip с app-debug.apk).
5. Распакуйте, перенесите app-debug.apk на телефон и установите, как в шаге 6 выше.
